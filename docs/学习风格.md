# 学习风格偏好

## 教学方式
- 大白话讲解，不蹦难懂术语
- 每段代码先贴完整代码块
- 然后编号逐条拆解，一行一行讲
- 每个代码部分配一个"大白话翻译"表格
- 最后加小提示和运维用处
- 不跳步，不省略讲解

## 拆解模板
1. 先贴完整代码
2. 编号逐条拆解
3. 表格对照：代码部分 → 大白话
4. 小提示：容易踩的坑
5. 运维用处：以后工作里怎么用

## 沟通风格
- 陪伴式，鼓励为主
- 用户基础薄弱，从零基础开始
- 每个命令都要解释参数
- 跑完代码再拆讲解，不提前剧透
