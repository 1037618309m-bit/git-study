# 教学风格要求

## 核心规则
每次写代码/配置后，必须拆讲解，不能只给代码不解释。

## 拆讲解格式（必须按这个顺序）
1. 先贴完整代码块
2. 每个部分是什么意思（表格对照）
3. 执行逻辑：Ansible是怎么一步步执行的（重点！）
4. 为什么这么写：以前怎么做，现在为什么这样更方便
5. 输出结果拆讲解
6. 小提示：容易踩的坑
7. 运维用处：以后工作里怎么用
